# Visual Programming Projects

A collection of desktop applications and experiments developed using **C#** and the **.NET** ecosystem. This repository focuses on building interactive user interfaces, event-driven programming, and mastering the visual aspects of software development.

---

## 🛠 Tech Stack

- **Language:** C#
- **Frameworks:** .NET 8.0+ / .NET Framework (WPF, WinForms)
- **IDE:** RIDER
